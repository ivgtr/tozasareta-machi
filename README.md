# 孤立した町の30日間

![災害対策本部から孤立した山村を見つめる4人](docs/assets/key-visual-ops-room.png)

> 今日を生き延びるために備蓄を使うか、明日のために温存するか。

災害で外部との交通が途絶えた小さな町を舞台に、再接続までの30日間を耐え抜くターン制運営シミュレーションゲームです。

[ブラウザで遊ぶ](https://ivgtr.github.io/tozasareta-machi/)

## 町の30日間

プレイヤーは町の臨時対策責任者となり、限られた人員、食料、電力、医療、備蓄を管理します。

町では毎日、発電設備の故障、食料不足、住民の反発、交易や探索など、さまざまな問題が起こります。すべてを同時に解決することはできません。

誰をどの仕事へ送り、何を諦め、どの物資を明日へ残すか。その一つひとつの判断が、町と人々の明日を変えていきます。

町にもともと暮らす4人に加え、避難者や個性的なユニークユニットが加わることがあります。得意分野や特性を見極めて配置する一方、増えた仲間の食料も確保しなければなりません。

30日後に迎える結末は、町の復旧状況、住民の協力、そして払った犠牲によって変化します。

## 開発

```bash
npm ci
npm run playwright -- install chromium
npm run test:e2e
```

ブラウザ回帰テストのスクリーンショットは `test-results/e2e` に出力されます。
