# 経済再編とプレイ感改善

[経済とバランス](./09-経済とバランス.md)・[選択型イベント設計](./16-選択型イベント設計.md)・[期間修正イベント設計](./17-期間修正イベント設計.md) を改変し、実プレイのフィードバック4点（探索の発火・帰還の可視性・備蓄の枯渇・士気の停滞）に対応する計画。数値はすべて仮置きで、sim で確定する。

**状態: 実装済み（v1.3 / E1–E4 コミット済み）**

**実装結果（E4 確定値）**: 仮数値 `food.decay:5` / `morale.decay:2` / 炊き出し予算15 / procure 15→12 を採用。加えて **`foodPerUnit:4→5`** を追加（計画外のデカップリングレバー。人員比例の食料消費で、終盤に人員が増える熟練にのみ強く効く）。sim 実測: **熟練 47% / 無作為 3%**（40/60ゲーム）、熟練 53% / 無作為 1%（200/120ゲーム）。

**検討したが不採用**: 食料瀕死時の救済イベント（`emergency_ration`）を追加して無作為の底上げを試みたが、食料逼迫構成では熟練も閾値に到達して恩恵を受け（熟練 +10pt 以上）、熟練~50% の目標と衝突したため削除。食料圧を緩めると熟練が 80% 超に跳ねるため、無作為と熟練の完全な分離は現機構では達成不可。full_recovery は食料圧が電力・医療投資を圧迫し autoAssign では 0 だったが、**その後の調査で「狙ったプレイなら到達可」と判明し、バランス無変更で決着**（§7 決着記録）。

## 1. 確定した方針

### 設計原則

1. **核を変えない**: 備蓄の緊張は強化。食料をメンテ必須にして「道路一強」を解消し、全資源が管理対象に戻る。
2. **純粋・決定的を保つ**: 減衰・procure・帰還スポットライト化はすべて step 内で完結。同じ seed + 同じ行動 = 同じ結果。
3. **数値は balance.ts**: food.decay / morale.decay / procure レート / soup 予算額はすべて BALANCE に集約。
4. **ゲート制**: E1–E4 各マイルストーン末にゲートを確認。1マイルストーン = 1コミット。
5. **既存構造を維持**: 選択イベント、Modifier 機構、到着/探索の構造は変更しない。

### 非目標

- 道路復旧の coef 変更（0.1 で生存率25点揺れるナイフエッジのため、食料減衰で代替）
- 探索の経済（cost・帰還率・報酬）の変更
- `SAVE_VERSION` の引き上げ（後述 §4: 変更なし）
- イベント weight の再調整（現状維持）

### 1.1 探索の発火ガード（#1）

`expedition` の `when` に `c.state.stockpile >= BALANCE.expedition.cost` を追加。発火自体が止まる（1行）。

### 1.2 帰還のスポットライト化（#2）

再生機構は「`event:*` source + `unit:{id}` ターゲット → arrival スポットライト（ポーズ+カード+続行）」を既に持つ（usePlayback.ts:32-38）。**機構無変更で**:

- settlement.ts の帰還 effect の source を `'settlement'` → `'event:expedition_return'` に変更
- 帰還 effect 群に `unit:{id}` ターゲットの effect を混ぜる → buildBeats が自動でスポットライト化

RNG 消費は現状通り settlement 内なので決定性は不変。帰還専用コピー（「◯◯が帰還した」+成果）は任意拡張。

### 1.3 経済再編（#3）

**方針**: 予算=唯一の希少ハブ / 食料=漏れるバケツ / 備蓄=「明日のために貯める」対象 / 士気=予算競争の一員。

| レバー | 内容 | 採用 |
| --- | --- | --- |
| L1 | **食料の減衰**（新規）。power(10)/medical(8) と同じ流儀の固定値。道路復旧が「食料メンテ」になり永続解決を消す | ✅ |
| L2 | 道路復旧の coef 引き下げ（ナイフエッジ） | ❌ L1 で代替 |
| L3 | **炊き出しコスト: 備蓄15 → 予算15**。士気が電力・医療と同じ予算競争に入る | ✅ |
| L4A | **常設トグル「備蓄を調達」**（DecisionBoard、ration と対）。予算→備蓄の毎日の戦略判断 | ✅ |
| L4B | **trade_offer に `buy_stockpile`**（予算15 → 備蓄+12）追加 | ✅ |
| — | 食料上限超過→備蓄転換 | ❌ 道路一強を加速するため却下 |

### 1.4 士気の基底減衰（#4）

`morale.decay` を新設（仮: 2/日、「孤立生活のストレス」）。安定時は 基底-2 + calm+2 = 差し引き0（均衡）。上げるには炊き出し/好イベントが必要。放置すると prodHighAt(50) を割り生産低下。

## 7. full_recovery 到達性の決着記録（v1.3 後の調査）

**結論**: full_recovery（day 30 で power≥70 かつ medical≥70 かつ casualties≤1）は到達不能ではなかった。「sim で 0」は autoAssign（おまかせ配置）が full_recovery を最適化しないためであり、**人間が狙うプレイでは到達可**。バランス値・イベントは無変更で決着した。

### 7.1 証拠（tests/full-recovery.test.ts）

熟練 sim と同じ seed（1000–1059 の 60 ゲーム）で、full_recovery を狙う決定論的戦略を回した結果:

| ending | 件数 |
| --- | --- |
| full_recovery | **37** |
| managed_sacrifice | 9 |
| self_governance | 1 |
| collapse | 13 |

- 到達不能は再現されず、過半数で到達。テストは `endings.full_recovery >= 10` を表明し、到達性の回帰を検出する。
- 同一 seed・決定論的戦略なので再現可能（`npx vitest run tests/full-recovery.test.ts`）。

### 7.2 狙うプレイの方針（autoAssign との差分）

full_recovery のボトルネックは「食料圧の下で、終盤に電力・医療へ投資する余裕を作れるか」。autoAssign は毎日その日の最大産出（=食料/道路復旧）に貪欲で、終盤目標への投資・配給・調達・交易の判断をしない。狙うプレイは以下を行う:

1. **序盤–中盤は電力・医療を維持帯（50–70）で守る**: 各1–2人で十分。電力≥50 で予算ボーナス（+15）を確保し、医療の追加減衰（power<30）を避ける。
2. **終盤（day 25–）に電力・医療へ集中投資**: 各2人に増員し、減衰（power -10/日、medical -8/日）を上回る産出で 70 台へ押し上げる。発電機故障・台風等の妨害イベントを吸収する余裕を持たせる。
3. **食料は備蓄・交易・配給で緩衝**: road 産出が消費（人員×5+減衰5）に届かない期間は、備蓄取崩し・`buy_food`・緊急時の配給（ration）で繋ぎ、casualties（餓死）を 1 以下に抑える。
4. **士気を炊き出しで下支え**: 士気0の崩壊と生産倍率低下を防ぐ。

### 7.3 なぜ autoAssign では 0 のままか（設計どおり）

- autoAssign は `placementValue` の増分が最大の任務へ逐次配置する（`actions.ts`）。食料圧が高いほど道路復旧（食料）の優先度が上がり、電力・医療への終盤投資に人員を回さない。
- `ration:false / procure:false` 固定で、選択イベントも最適化しないため、食料・備蓄・予算の緩衝を能動的に作れない。
- これは欠陥ではなく「おまかせ配置＝生存狙いの汎用ヒューリスティック」の仕様。full_recovery は終盤目標への計画的投資を要求する上位エンドとして位置づける。

### 7.4 バランス無変更の理由

- 狙ったプレイで到達可である以上、レバー（`effect.repair.base`/`medical.base` 引上げ、power/medical の decay 調整、full_recovery 閾値の緩和等）を動かせば熟練~47% / 無作為~3% の確定済みバランスを再び揺らすリスクがあるだけ（E4 で base 2→3 が勝率を押し上げて不採用とした教訓と同種）。
- 数値・イベントを変えていないため、熟練 47% / 無作為 3% および各 ending 分布は変更前後で同一（sim 再測定で確認済み）。
- 新規イベント（終盤の電力・医療を補強する選択イベント等）も不要と判断。候補プールと RNG を動かして分布をシフトさせる副作用に見合う効果がないため。
