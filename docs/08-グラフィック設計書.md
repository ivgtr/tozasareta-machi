# グラフィック設計書: 孤立した町の30日間

UI に必要なグラフィックのアセット戦略。初期はコード生成のプレースホルダで成立させ、将来はAI生成画像へ**ファイル追加だけ**で差し替えられることを保証する。

---

## 1. 方針と確定事項

| 項目 | 決定 |
| --- | --- |
| 基本戦略 | 2トラック制（コード描画 / 画像スロット） |
| アイコン | 全スロットを割り当てる。**手描きSVGは作らず「文字タイル」プレースホルダ**で描画 |
| 仮画像方式 | 統一テンプレート + アートスロット・フォールバック |
| 町のスカイライン | 採用。状態と連動するコード描画の「生きた」要素 |
| AI生成 | 将来対応。スタイルガイド + プロンプト雛形を本設計書に同梱 |

---

## 2. 2トラック制

| トラック | 内容 | 描画手段 | 将来のAI画像 |
| --- | --- | --- | --- |
| **A: コード描画** | UIプリミティブ（パネル/ボタン/ゲージ/カーソル/トークン）、アンビエント背景、スカイライン | CSS / SVG / Canvas | 差し替え不要（UIそのもの） |
| **B: 画像スロット** | アイコン、肖像、イベントカード、エンディングKV、ブリーフィング背景 | 現在はプレースホルダ、将来はビットマップ | スロットごとに生成して配置 |

トラックBのすべては**同一のフォールバック機構**（§3）を通す。トラックAは「永遠にコード」であり、AI画像の対象外。

---

## 3. アートスロット・フォールバック機構

### 3.1 解決順序

すべてのイラストは `kind` + `id` で参照する。実ファイルがあればそれを、なければプレースホルダを描く。

```tsx
<PixelArt kind="event" id="refugees" />
// 1) assets/event/refugees.png が存在 → <img>（image-rendering: pixelated）
// 2) なければ → PlaceholderArt（マニフェストの glyph + color で描画）
```

### 3.2 配置規約と自動検出

```
src/ui/assets/
  icon/{id}.png        # 48×48
  event/{id}.png       # 128×80
  portrait/{id}.png    # 48×48
  ending/{id}.png      # 192×108
  briefing/{id}.png    # 320×180
```

Vite の `import.meta.glob('../assets/**/*.png')` で起動時にルックアップを構築する。**PNGを置けばコード無変更で自動反映**される。これが「AI画像を足す = ファイルを置くだけ」の根拠。

### 3.3 マニフェスト

各スロットはコード側のマニフェスト（データ）で宣言され、プレースホルダはこれを読んで描画する。

```ts
interface ArtSpec {
  id: string;
  kind: 'icon' | 'event' | 'portrait' | 'ending' | 'briefing';
  glyph: string;    // フォールバックの文字
  color: string;    // デュオトーン/枠の色トークン
  label: string;
}
```

## 5. プレースホルダのデザイン

灰色ボックスにはしない。題材（災害対策本部）に沿った「資料/写真」表現で統一する。すべてコード生成、ビットマップ不要。

### 5.1 文字タイル（アイコン）

JRPGの漢字アイコンに倣う。ピクセル枠のチップ中央に1文字。

```
┌───┐
│ 食 │   枠: ピクセル3px（frame-hi / frame-lo）
└───┘   文字: DotGothic16 700、色 = カテゴリカラー
        背景: night-700 + 下部へデュオトーン減衰
```

- サイズは CSS 変数で sm(20px) / md(28px) / lg(40px)。
- 文字はあくまで**識別子**であり、AI画像が届けば同じスロットに差し替わる。

### 5.2 イベントカード

無線写真/捜査資料を模す。

```
+--------------------------+
|   [デュオトーン背景]      |
|        ( 人 )            |  中央に文字タイル(lg)
|   ▓▓▒▒░░ ディザ ░░▒▒▓▓   |  ムード色のディザパターン
| ─走査線─                  |
| 避難者             [PHOTO/現像中] |  左下ラベル+右上スタンプ(cyan)
+--------------------------+
```

- 背景 = `night-800 → ムード色` のデュオトーン。
- イベントごとに「文字 + 色」が異なるため、20枚が個別に見える。

### 5.3 肖像

```
┌────┐
│ ◔◡◔ │  人物シルエット（CSS/SVGの汎用バスト）
│ 医  │  下部に役割の文字タイル
└────┘   枠色 = 役割カラー
```

### 5.4 エンディングKV

結末名を Press Start 2P / DotGothic で大きく + デュオトーン + 走査線。4結末は個別のムード色（完全復旧=green、管理された犠牲=amber、住民自治=cyan、崩壊=red）。

### 5.5 ブリーフィング背景（作戦地図）

ビットマップなしで「非常時」を出す。CSS/SVG で描く作戦地図:

- 暗いグリッド（地図の緯度経度風）
- 町のマーカー（ピクセルの点）
- **寸断された道路線**（途中で途切れた破線 = 孤立のメタファ）
- 点滅する事故マーカー（赤、ステップ点滅）
- 走査線 + 隅の「緊急派遣要請」スタンプ

## 6. 町のスカイライン（生きた要素）

状態を「町の眺め」として表示する、題材固有のコード描画レイヤー。

- **実装**: 小さなピクセルビル群を SVG rect で一度生成。各建物の「窓」をグリッドとして持つ。
- **状態連動**:
  - 点灯する窓の比率 = 電力に比例（`litRatio = power/100`）
  - 電力低下 → 窓が不規則に瞬く（opacity のステップアニメ）
  - 士気低下 → 全体が暗く沈む（彩度/明度フィルタ）
  - 危険（食料尽・暴動）→ 一部が赤く点滅
- **配置**: AmbientBackdrop の最前面（層1.5）。デスクトップでは画面下部に帯状、モバイルでは縮小。
- AI画像の対象外（毎フレーム状態を映すUIであるため）。

## 7. AI生成スタイルガイド + プロンプト雛形

### 7.1 全スロット共通スタイルガイド

生成物がレトロUIと乖離しないための固定制約。

- **解像度**: スロットごとのピクセル原寸（§3.2）。拡大表示は `image-rendering: pixelated`。
- **パレット**: 以下に限定。`#0a0e24 #131740 #1c2258 #e8ecff #ffc857 #ff5f66 #5ee6a8 #6fd8ff #ffd94a`
- **作風**: 16-bit ピクセルアート。可視ディザリング。**アンチエイリアスなし**（輪郭はくっきり）。
- **雰囲気**: 夜の孤立した小さな町、災害対応の緊張感。彩度は抑えめ、シグナル色を差し色に。
- **禁止**: 実写調、グラデーション多用、高彩度、现代的なUI要素の描き込み。

### 7.2 スロット別プロンプト雛形

```
[EVENT / 128×80]
16-bit pixel art, limited palette (#0a0e24,#1c2258,#e8ecff,#ffc857,#ff5f66,
#5ee6a8,#6fd8ff), visible dithering, no anti-aliasing, crisp pixels.
Night scene of an isolated small town during disaster response:
{イベント内容の1文}. Duotone leaning toward {ムード色}.
Small silhouetted figures, moody, dark. {補足}.

[PORTRAIT / 48×48]
16-bit pixel art bust portrait of a {役割}, limited palette as above,
dithering, no AA. Accent color {役割カラー}. Serious, tired but resolute.

[ENDING / 192×108]
16-bit pixel art key visual expressing "{結末の意味}".
Palette/dithering/no-AA as above. Dominant mood {ムード色}.

[BRIEFING / 320×180]
16-bit pixel art top-down emergency operations map of a mountain town
cut off by a landslide, severed roads, incident markers.
Dark navy base, amber/red markers. Palette/dithering/no-AA as above.
```

### 7.3 生成時の検証チェックリスト

- [ ] 原寸がスロット解像度と一致するか
- [ ] パレット外の目立つ色が出ていないか
- [ ] AA/ぼかしが入っていないか（`pixelated` で拡大して確認）
- [ ] 夜藍の背景に沈みすぎていないか（枠内でのコントラスト）

## 8. 実装順序（推奨）

1. マニフェスト（§4）+ `PixelArt` / `PlaceholderArt` コンポーネント

3. 文字タイル + イベントカード + 肖像プレースホルダ
4. ブリーフィング作戦地図
5. スカイライン（状態連動）
6. （将来）AI画像の生成・配置 → 自動反映を確認
