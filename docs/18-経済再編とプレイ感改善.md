## 1. 確定した方針

### 1.1 探索の発火ガード（#1）

`expedition` の `when` に `c.state.stockpile >= BALANCE.expedition.cost` を追加。発火自体が止まる（1行）。

### 1.2 帰還のスポットライト化（#2）

再生機構は「`event:*` source + `unit:{id}` ターゲット → arrival スポットライト（ポーズ+カード+続行）」を既に持つ（usePlayback.ts:32-38）。**機構無変更で**:

- settlement.ts の帰還 effect の source を `'settlement'` → `'event:expedition_return'` に変更
- 帰還 effect 群に `unit:{id}` ターゲットの effect を混ぜる → buildBeats が自動でスポットライト化

RNG 消費は現状通り settlement 内なので決定性は不変。帰還専用コピー（「◯◯が帰還した」+成果）は任意拡張。

### 1.3 経済再編（#3）※壁打ちの結論

**方針**: 予算=唯一の希少ハブ / 食料=漏れるバケツ / 備蓄=「明日のために貯める」対象 / 士気=予算競争の一員。

| レバー | 内容 | 採用 |
| --- | --- | --- |
| L1 | **食料の減衰**（新規）。power(10)/medical(8) と同じ流儀の固定値。道路復旧が「食料メンテ」になり永続解決を消す | ✅ |
| L2 | 道路復旧の coef 引き下げ（0.1 で生存率25点揺れるナイフエッジ） | ❌ L1 で代替 |
| L3 | **炊き出しコスト: 備蓄15 → 予算15**。士気が電力・医療と同じ予算競争に入る | ✅ |
| L4A | **常設トグル「備蓄を調達」**（DecisionBoard、ration と対）。予算→備蓄の毎日の戦略判断 | ✅ |
| L4B | **trade_offer に `buy_stockpile`**（予算15 → 備蓄+12）追加 | ✅ |
| — | 食料上限超過→備蓄転換 | ❌ 道路一強を加速するため却下 |

### 1.4 士気の基底減衰（#4）

`morale.decay` を新設（仮: 2/日、「孤立生活のストレス」）。安定時は 基底-2 + calm+2 = 差し引き0（均衡）。上げるには炊き出し/好イベントが必要。放置すると prodHighAt(50) を割り生産低下。

| リスク | 影響 | 対策 |
