# 音響設計・実装契約

Issue #19 PR13で実装したSound / Game Feelの正典。音は補助チャネルとし、情報の正は視覚Presentationに維持する。

## 1. 構造

- `src/scene/audio/audio-cues.ts`: `select / confirm / cancel / assign / unassign / invalid`、Playback importance、Story tone、arrival、warning等の意味カテゴリと短い16bit風音列
- `src/scene/audio/audio-director.ts`: AudioContext解禁、SFX envelope、Planning/危機ambience、Sound設定同期、終了処理
- `PlaybackPresentationCoordinator`: PR12の`minor / normal / major`とFlow toneを音カテゴリへ投影
- `PlayScene`: 操作・Story・Choice・町のdanger状態をAudioDirectorへ調停
- `TitleScene` / `MenuPresentation`: Sound ON/OFFと初回ユーザー操作でのAudioContext解禁

Presentationは音源パスや発振器を直接知らず、意味カテゴリだけを発火する。ゲームコア・GameState・セーブ形式に音響stateを追加しない。

## 2. 音響内容

| 分類 | 実装 |
| --- | --- |
| UI | 選択、確定、取消、配置、解除、不可 |
| Playback | minor、normal、major、施設行動 |
| Story | threat、boon、arrival |
| Ambience | Planning基底、danger時の危機差分 |

反復疲労を避けるため、minorと通常選択は短い単音・低ゲインにし、複音はmajor、threat、boon、arrivalへ限定する。イベント個別音や人物個別曲は持たない。

## 3. 技術判断

バイナリ音源を持たず、Web Audioで短いSFXと抑制した連続ambienceを手続き生成する。これにより次を満たす。

- イベント追加時の音源制作・ロード追加が不要
- GitHub Pages配信サイズを増やさない
- 意味カテゴリ、音量、envelopeをコード上の一箇所で検証できる
- Planningから危機への状態差分を少数レイヤーで表現できる

AudioContextはSound ONかつ最初のユーザー操作後だけ生成・resumeする。タイトル遷移ではambienceを停止し、Game破棄時は全nodeとAudioContextを終了する。

## 4. 設定・非聴覚契約

- 設定は`Settings.sound: boolean`。既存設定にはdefault `true`を補完する
- タイトルと指揮所メニューの双方から切替可能
- OFF時はSFXとambienceを即時停止し、再度ONにすると現在の町状態へ同期する
- 音だけで状態・選択可否・危機・結果を伝えない
- reduced-motionとSound OFFは独立し、どちらでも操作経路と情報量を失わない

## 5. 非目標

- 音声・ナレーション
- 大量のBGM、イベント個別曲、人物別テーマ
- Gamepad
- ゲームコア側の音関連state
