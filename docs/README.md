# 孤立した町の30日間

ブラウザ上で動作するターン制運営シミュレーションゲームの設計ドキュメント。

災害で外部との交通が途絶えた小さな町を舞台に、プレイヤーは臨時対策責任者として、限られた人員と物資を配分しながら再接続までの30日間を耐え抜く。

## 実装状況

- **v1**（P1–P9 完了）: 基本システム。
- **v1.1**（U1–U3 完了）: 作業員を**ユニークユニット**へ置換（適性・特性・成長・負傷・死亡・離脱・加入）。バランス確定: **無作為 20% / 熟練 98% 生存**、全4エンディング到達可。
- **ユニークパロディ化**: 30体を実在人物（故人）15 + アニメ/ゲームキャラ15のパロディとして実装。
- **汎用肖像画 R3/R4 完了**: ランダム加入者の決定的割り当て・manifest・旧セーブ正規化。PNG 導入済み（ユニーク20+汎用8。追加ユニーク10体はフォールバック表示）。
- **状態別スカイライン完了**: 山村の通常/停電/危険3バリアントを導入済み。
- 正典: ゲームコアは [12-ユニット設計](./12-ユニット設計.md) を正とし、06/09 の作業員・人員記述は旧モデル。
