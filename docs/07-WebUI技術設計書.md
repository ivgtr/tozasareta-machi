# WebUI 技術設計書: 孤立した町の30日間

要件書・参考研究・技術設計書（06）に基づく、WebUI 層の実装設計。アートディレクション、画面構成、コンポーネント、中核インタラクション、プレイバック、レスポンシブ、アクセシビリティまでを対象とする。

---

## 1. 方針と確定事項

| 項目 | 決定 |
| --- | --- |
| アートディレクション | レトロゲーム調（ドットゴシック + CRT 表現） |
| 画面構成 | 対策本部の3ゾーン（状況 / 決定 / 記録）を非対称に配置 |
| 中核操作 | 作業員トークンのドラッグ&ドロップ（タップ選択フォールバック併設） |
| 解決の表現 | Effect を1件ずつ再生する逐次プレイバック（スキップ可） |
| 対応デバイス | 完全レスポンシブ（デスクトップ3列 → モバイル縦積み） |
| 状態連動 | 背景・ゲージ・警報が game state に反応する |

前提（06 より変更なし）: ゲームコアは DOM 非依存の純粋 reducer。UI は `step` を直接呼ばず、store 層（`commitDay` dispatch / undo / 永続化）を経由する。プレイバックは store と view の間に置く表現層。

---

## 2. アートディレクション

### 2.1 方向性

16bit 風のJRPGコマンド画面を参照する。**単色アクセントの平面な暗画面にはしない**。深藍の夜を基底に、複数のシグナル色と多層背景（空・天候・走査線・ヴィネット）を重ね、状態と連動させる。角は丸めず、ピクセル境界線で引き締める。

### 2.2 カラー（デザイントークン）

```css
:root {
  /* 基底（夜） */
  --night-900:#0a0e24;  /* ページ背景 */
  --night-800:#131740;  /* セクション背景 */
  --night-700:#1c2258;  /* パネル塗り */
  --night-600:#252c6e;  /* パネル hover / 内側 */

  /* 枠・文字 */
  --frame-hi:#e8ecff;   /* ピクセル明枠 */
  --frame-lo:#5a6190;   /* ピクセル影枠 */
  --ink:#e8ecff;        /* 本文 */
  --ink-dim:#9aa3cc;    /* 次要文字 */

  /* シグナル（複数色を使う） */
  --amber:#ffc857;      /* 警戒 */
  --red:#ff5f66;        /* 危険 */
  --green:#5ee6a8;      /* 安定 */
  --cyan:#6fd8ff;       /* 情報・telemetry */
  --gold:#ffd94a;       /* 日数カウンタ・強調 */
}
```

### 2.3 タイポグラフィ

**表示用（数字・ラテン）と本文用（日本語）を分離**する。

| 用途 | フォント | サイズ |
| --- | --- | --- |
| 日数カウンタ / 数値 / "PRESS START" | Press Start 2P | clamp(56,8vw,96) / 28 |
| 見出し | DotGothic16 700 | 20 |
| 本文・状態語 | DotGothic16 400 | 15 |
| ラベル・telemetry | DotGothic16 400、letter-spacing .08em | 12 |

サイズジャンプ（巨大な日数 → 中見出し → 小ラベル）で強い階層を作る。DotGothic16 は可読性確保のため行間に余裕を持たせる。Google Fonts から preconnect 付きで読み込み、`font-display: swap`。

### 2.4 パネル（JRPG コマンドウィンドウ風）

基本プリミティブ `PixelPanel`:

```css
.panel {
  background: var(--night-700);
  border: 3px solid var(--frame-hi);          /* 明枠 */
  box-shadow: inset 0 0 0 3px var(--night-800),/* 内側の暗い縁 */
              6px 6px 0 rgba(0,0,0,.45);       /* ピクセルドロップシャドウ */
}
```

ボタン `PixelButton` は hover で枠色反転 + 1px 沈み、active で 2px 沈む。角は丸めない。

### 2.5 多層背景（AmbientBackdrop）

静的な壁紙ではなく、state を購読して変化する層を重ねる。すべて `transform`/`opacity` のみでアニメートする。

| 層 | 内容 | 状態連動 |
| --- | --- | --- |
| 1 空 | 深藍グラデーション + ドット雲（steps() で低速流れる） | 日数で微妙に変化 |
| 2 天候 | ピクセル雨筋（約40本、steps() 落下） | 豪雨イベント時に出現 |
| 3 走査線 | `repeating-linear-gradient` の CRT 線 | 常時（reduced-motion で静止） |
| 4 ヴィネット+状態色 | 周辺減光 + カラーティント | 士気低→沈む、食料尽→赤パルス |

## 3. 画面構成

### 3.1 デスクトップ（≥1100px）: 3ゾーン

```
+--------------------------------------------------------------+
| TopBar  第12日/30日  【警戒】食料不足のおそれ   [待機][再開]   |
+----------------+----------------------------+----------------+
| StatusWall     | DecisionBoard               | RecordFeed     |
|  食料 [▮▮▮▯▯] |  ┌発電所の修理┐ ⊕⊕ → +電力  | ── 第11日 ──  |
|  電力 (計器)   |  ┌道路復旧┐  ⊕   → +食料    |  配給を絞った  |
|  医療 ✚✚✚✧   |  ┌医療班増員┐               |  → 不満が上昇  |
|  士気「不安が  |  ┌炊き出し┐                 | ── 第10日 ──  |
|   広がって…」 |  作業員プール ⊕⊕⊕⊕         |  発電機が故障  |
|  ─人員─       |        [ 作戦を開始する ]    |  ...           |
+----------------+----------------------------+----------------+
   状況壁(読む)        意思決定面(決める)         無線ログ(振り返る)
```

### 3.2 モバイル（<700px）: 縦積み

```
+----------------------+
| TopBar(日数+警報短縮) |
| 状況HUD: 2x2 ゲージ   |  ← StatusWall をコンパクト化
| ─DecisionBoard─      |
|  任務スロット(縦並び) |
|  プール+作戦開始      |  ← 底部固定アクションバー(親指到達)
| ▸ 本部記録 (折り畳み) |  ← アコーディオン/ドロワー
+----------------------+
```

タブレット（700–1100px）は2列。StatusWall を上部の横帯に、RecordFeed を右列または下部に配置する。

### 3.3 オープニング（ブリーフィング）

汎用的なタイトルヒーローにしない。**着信した緊急派遣要請**として開く: 暗転したCRTに状況文が1文字ずつタイプされ（「豪雨により幹線道路崩落…貴殿を臨時対策責任者に任命する」）、最後に点滅カーソルつきの `▶ 指揮所へ` が現れる。レトロの作法（テキスト送り）と題材固有の導入を兼ねる。スキップ可。

### 3.4 エンディング

結果を「最終日報」風の1枚として表示。エンディング種別（06の4種）を大きな見出しで、主要指標（残食料・犠牲者・協力度）をピクセルゲージで総括し、「もう一度」で新規ブリーフィングへ。

## 5. 中核インタラクション: 作業員トークン

毎ターン必ず触る操作なので、最も手触りを重視する。

### 5.1 実装方式

- **HTML5 drag API は使わない**。モバイルのタッチに対応できず、スタイル制御も弱いため。
- **Pointer Events**（`pointerdown/move/up` + `setPointerCapture`）で実装し、マウス/タッチ/ペンを統一扱いする。
- **タップ選択フォールバック**: トークンをタップして選択 → 任務スロットをタップして配置。ドラッグが苦手な環境・ユーザの代替経路。
- **キーボード**: 任務スロット間を矢印キーで移動、Enter でトークン配置/回収。フォーカスは常に見える（`focus-visible`）。
- タッチターゲットは最小 44px。トークンは約 40px + 余白。

### 5.2 フィードバック

| 局面 | 演出 |
| --- | --- |
| トークン掴み | 1.1倍に拡大 + 影強調 |
| 任務 hover | 枠発光 + 点滅カーソル `▶`（クラシックなメニューカーソル） |
| ドロップ | 軽いバウンドでスナップ（steps() イージング） |
| 配置不可 | 枠が赤く短く点滅し、トークンがプールへ戻る |
| 数値変化 | 任務の予想効果（+電力 等）がチッキーに増減 |

### 5.3 確定（commit）

`CommitBar` の「作戦を開始する」は、有効な plan（作業員総数以内）の間のみ有効。押下すると入力をロックし、プレイバック（§6）へ移る。

## 6. 解決プレイバック

`commitDay` の結果を一度に見せず、**因果が追える順序で再生する**。ゲームコアが返す `effects[]` がそのまま台本になる（06）。

### 6.1 状態機械

```ts
type PlaybackPhase = 'idle' | 'playing' | 'done';
interface PlaybackState {
  phase: PlaybackPhase;
  queue: Effect[];    // step が返した effects
  index: number;      // 再生位置
}
```

### 6.2 進行

1. dispatch 時、store は新 state（最終値）と effects を得る。UI 側には **表示用 state**（`displayState`）を別に持ち、前日 state から開始する。
2. `usePlayback` がタイマーで `index` を進める。各 Effect について:
   - 対象ゲージ/数値を `useAnimatedNumber` で目標値へアニメート
   - 理由文を `RecordFeed` にタイプイン
   - イベント由来（`source: 'event:*'`）なら `PlaybackOverlay` から無線カードを差し込む
3. 全件再生 → `displayState = 最終 state`、`phase: 'done' → 'idle'`、入力ロック解除。
4. **スキップ**: ボタンまたは任意の Effect 領域タップで最終値へ即時ジャンプ。
5. **reduced-motion**: 自動スキップ（結果を即時表示、理由文のみ列挙）。

### 6.3 設計上の注意

- 実体の game state は既に最終値であり、プレイバックは**純粋に表現上のTween**である。store を巻き戻さないので、ロジックと同期が崩れない。
- タイミング定数（1件あたりのms、タイプ速度）は `data/ui-timing.ts` に集約し、バランス同様チューニング対象とする。

## 7. 状態連動と「生きている」表現

| 対象 | 演出 |
| --- | --- |
| 食料ゲージ | 残量バー。危険域で琥珀色点滅 |
| 電力 | 針/セグメント計器。低いと照明が瞬く（opacity の小刻み揺らぎ） |
| 医療 | 十字インジケータ。不足で彩度低下 |
| 士気 | 状態語（03のラベル関数）を大きく表示。閾値で文言と色が変わる |
| 食料尽 | 背景4層目に赤パルス |
| 豪雨イベント | 雨筋レイヤー出現 |
| 低士気 | ヴィネットが深く沈む |

## 8. アクセシビリティとパフォーマンス

### 8.1 アクセシビリティ

- `prefers-reduced-motion` で走査線点滅・雨・カウントアニメを静止/短縮。
- 日志・レポートは `aria-live` でスクリーンリーダに通知。
- 色だけでなく文言/アイコンでも状態を伝達（色覚多様性）。
- 全操作をキーボードで完結可能に（§5.1）。

### 8.2 パフォーマンス

- アニメーションは `transform`/`opacity` のみ。レイアウトプロパティを毎フレーム変えない。
- `useAnimatedNumber` の更新は当該ゲージのサブツリーに閉じ、毎ティックの全ツリー再レンダーを避ける。
- ピクセル素材は `image-rendering: pixelated`。雨粒はDOM要素（約40）に留め、canvas は不用意に導入しない。
- フォントは subset 指定で転送量を抑制。

## 9. 実装順序（推奨）

1. フォント + デザイントークン + ベースリセット
2. プリミティブ（PixelPanel / PixelButton / Gauge / TypeText）+ AmbientBackdrop
3. TopBar + StatusWall（ゲージ + 状態語 + Roster）
4. DecisionBoard（TaskSlot + WorkerPool）+ `useDragToken`
5. store 接続 + commit
6. `usePlayback` + RecordFeed + PlaybackOverlay
7. BriefingScreen + EndingScreen
8. レスポンシブ仕上げ + アクセシビリティ + reduced-motion
9. 磨き（マイクロインタラクション、任意でレトロ効果音）
