# スカイライン画像計画

**完了**: `town_normal` / `town_dark` / `town_danger` の3枚を導入済み。

[グラフィック設計](./08-グラフィック設計書.md)（§6 スカイライン / §7 スタイルガイド）に基づき、画面下部のスカイラインを**プロシージャルなビル群から孤立した山村のシルエットへ置き換える**ための画像制作計画。画像制作とコード実装は別トラックとし、本計画は画像制作者向けにアセット契約・プロンプト・ゲートを定める。

---

## 0. 背景と目的

現状のスカイラインは `Skyline.tsx` がプロシージャルSVGで描く**ピクセルビル群**。舞台は山あいの孤立した小さな町であり、都市のビル群は設定と不整合。これを山村のシルエットへ置き換える。

加えて、現状スカイラインには**窓の点灯数が電力に比例する**という「生きた」フィードバックがある（docs/08 §6）。単純な静的画像への差し替えはこの連動を失うため、本計画では**状態に応じて3枚のバリアントを切り替える**方式を採用する。3枚は**同じ構図・同じ屋根並び**で生成し、窓の灯りと差し色だけを変える。

### 進め方の原則

- **先にアセット契約を固定**: ID・寸法・パレット・構図を合意してから生成する。
- **3枚の構図を完全一致させる**: 屋根の並び・建物のフットプリント・光源は3枚で同一。変えるのは窓の点灯と差し色のみ。これが差し替え時の違和感をなくす最重要条件。
- **既存アセットと同じ作品世界**: `scene/night.png`（320×180）とピクセル密度・パレット・光源を揃える。
- **ゲート制**: 1バリアント = 1生成コール。基準バリアント（`town_normal`）を先に固定し、残り2枚はそれをスタイル参照にする。
- 画像は `src/ui/assets/skyline/{id}.png` に置くだけで自動反映される（`import.meta.glob` 検出）。

### 非目標

- 窓の個別点灯（連続的な電力連動）の再現。バリアント切替は**閾値ベース**のフィードバックとする。
- スカイライン以外の背景要素（雨・走査線・ヴィネット等の状態エフェクトはコード描画のまま残る）。
- アニメーション（点滅は既存CSSの `--danger` フィルタで代用可）。
- 画像内のテキスト・UI・枠の描画。

## 1. アセット契約

### 1.1 バリアントセット

| ID | 選択条件（コード側） | 見た目 | 差し色 |
| --- | --- | --- | --- |
| `town_normal` | 電力 ≧ 30 かつ danger 非該当 | 数軒の窓が琥珀色に点灯した静かな夜 | amber `#ffc857` |
| `town_dark` | 電力 < 30 | ほぼ消灯、かすかな灯りが1〜2軒。停電の町 | 暗色中心 |
| `town_danger` | danger フラグ（士気<20 or 食料0） | 赤系の非常灯、無線塔のビーコンが赤。緊張した夜 | red `#ff5f66` |

- 配置先: `src/ui/assets/skyline/{id}.png`
- フォールバック: 上記が無くても既存の汎用 `skyline/town.png`、それも無ければプロシージャルSVGが描画される。

### 1.2 寸法・形式

| 項目 | 指定 |
| --- | --- |
| 完成サイズ | **320×64 PNG**（幅は `scene/night.png` と同じ320でピクセル密度を統一。帯状のため高さは64） |
| 背景 | 不透明の濃紺 `#0a0e24`。透過処理は行わない |
| 色 | `#0a0e24 #131740 #1c2258 #e8ecff #ffc857 #ff5f66 #5ee6a8 #6fd8ff #ffd94a` の9色以内 |
| 形式 | indexed PNG、アンチエイリアスなし |

### 1.3 構図の固定条件

- 横長の山村シルエット。画面下部に家屋の並び、背後に低い山並み。
- **3枚で完全に一致**させるもの: 家屋の位置・幅・屋根の形状、祠/神社の位置、無線塔の位置、松の木の位置、山並みの稜線。
- 家屋は切り妻屋根（急勾配の木造）。1軒だけ反り屋根の祠/神社を混ぜる。
- 無線塔を1本入れ、`town_danger` ではその先端が赤く点灯する（他バリアントでは暗いか琥珀）。
- 夜の左上光源、右下に深い影を共通化する（`scene/night.png` と揃える）。
- 小サイズ・全幅表示の両方で読めるよう、細部を詰め込みすぎない。

### 1.4 描くもの（山村の語彙）

- 切り妻屋根の木造家屋（数軒、高さ不揃い）
- 反り屋根の祠または小さな神社
- 赤く点滅する無線塔（孤立のメタファ）
- 散在する松の木（暗いシルエット）
- 背後の低い山並み
- **描かないもの**: 高層ビル、近代建築、車、ネオン、現代的な構造物

## 2. 画像生成プロンプト

### 2.1 共通プロンプト

全バリアントで同一の本文を使い、末尾の `{lighting}` と `{accent}` だけを差し替える。

```text
Use case: stylized-concept
Asset type: 320x64 in-game skyline strip for a retro disaster-management game
Primary request: Create one wide silhouette strip of a small isolated mountain village at night.
Scene/backdrop: Opaque flat dark navy background (#0a0e24), a low mountain ridge behind the village.
Subject: Traditional wooden houses with steep gabled roofs of varying heights, one small shrine with a curved roof, a single tall radio mast, scattered dark pine trees.
Style/medium: 16-bit pixel art, visible dithering, crisp hard pixel edges, no anti-aliasing.
Composition/framing: Wide horizontal strip, village along the bottom edge, mountain ridge behind, generous dark sky above.
Lighting/mood: Sparse cold night light from upper left, deep shadow to the lower right, restrained and serious.
Color palette: Use only #0a0e24 #131740 #1c2258 #e8ecff #ffc857 #ff5f66 #5ee6a8 #6fd8ff #ffd94a. {accent}
Lighting variant: {lighting}
Constraints: Keep the EXACT same roofline, building footprint, shrine, radio mast, trees, and mountain ridge as the approved reference; change only the window lights and accent color. Readable at full width; match the approved reference's framing, pixel density, and background.
Avoid: text, letters, numbers, UI frame, badge, watermark, tall buildings, modern architecture, cars, neon, photorealism, smooth gradients, soft edges, transparent background.
```

### 2.2 バリアント別差し替え

| バリアント | `{lighting}` | `{accent}` |
| --- | --- | --- |
| `town_normal` | `A handful of windows glow warm amber. A quiet, settled night. Restrained and calm.` | `Emphasize warm amber #ffc857 in the lit windows.` |
| `town_dark` | `Nearly all windows dark, only one or two faint amber lights remain. A blackout; the village holds its breath. Mostly #0a0e24 and #131740, deep shadows.` | `Almost no accent; keep the strip very dark.` |
| `town_danger` | `Sparse windows lit an uneasy red, the radio mast beacon glowing red. A tense, alert night.` | `Emphasize red #ff5f66 in the few lit windows and the mast beacon.` |

### 2.3 制作手順

1. `scene/night.png` と既存イベント画像をパレット・ディザリング・光源の参照として確認する。
2. `town_normal` を単独で生成し、構図・山村の語彙・小サイズでの認識性を修正して**基準画像を固定**する。
3. 基準画像をスタイル参照（構図の正）とし、`town_dark` / `town_danger` を**1枚1生成コール**で制作する。構図と光源は変えない。
4. 3枚を同じ倍率で並べ、屋根並びとフットプリントが一致しているを目視確認する。
5. 近傍法で320×64へ縮小し、固定パレットへ量子化する。
6. 採用品のみを `src/ui/assets/skyline/` に配置する。

## 3. 画像ゲート

- [ ] 3枚が320×64の不透明PNG（背景 `#0a0e24`）
- [ ] 使用色が指定9色の範囲内
- [ ] **3枚で家屋・祠・無線塔・松・山並みの位置と形状が一致**し、差分が窓の灯りと差し色のみ
- [ ] ビル群・近代建築・車・ネオンが含まれない（山村の語彙のみ）
- [ ] `town_normal` で窓の琥珀、`town_dark` でほぼ消灯、`town_danger` で赤の非常灯が明確に読み取れる
- [ ] 光源（左上）と影（右下）が `scene/night.png` と一致する
- [ ] テキスト・UI・透過・未指定色・滑らかな勾配がない
- [ ] 既存のシーン・イベント画像と同じ作品世界に見える

## 4. 実装側での扱い（参考・別トラック）

画像制作者の作業ではないが、コンテキストとして共有する。

- `Skyline.tsx` が状態からバリアントIDを選び、`resolveArtUrl('skyline', id)` で解決する。選択順は `town_danger` → `town_dark`（電力<30）→ `town_normal`。
- 解決に失敗したら汎用 `skyline/town.png` → プロシージャルSVGの順にフォールバックする。
- 低士気（<40）の gloomy 表現は、画像に対しても既存のCSSフィルタ（`brightness/saturate` 低下）を適用する。
- 閾値（電力30 / 士気40）は `src/game/data/balance.ts` に集約する。
- プロシージャルSVGフォールバックも、画像未着時にビル群ではなく**村のシルエット**（切り妻屋根+松+山並み）を描くよう整形する。窓の電力連動ロジックは維持。
